# Kebijakan Privasi – Lapor Kampus
Versi M01 · 2 November 2026 (Data lokal – belum ada server)

## 1. Data yang Kami Simpan
Kami hanya menyimpan data minimal yang diperlukan untuk mencatat laporan kerusakan fasilitas kampus:
- NIM / Identitas Pengguna (untuk verifikasi pelapor).
- Foto Kerusakan Fasilitas (sebagai bukti kondisi fisik fasilitas).
- Deskripsi Laporan & Lokasi Gedung/Ruangan (detail kerusakan fasilitas).

## 2. Di Mana Data Disimpan
- Pada versi M01 ini, seluruh data disimpan **hanya di perangkatmu** menggunakan penyimpanan lokal (In-Memory / Local Storage).
- Tidak ada akun online dan data tidak dikirim ke server luar mana pun pada tahap ini.

## 3. Siapa yang Bisa Melihat
- **Hanya kamu.** Tim pengembang tidak memiliki akses atau kemampuan untuk melihat data laporan yang disimpan secara lokal di perangkatmu.

## 4. Hakmu
- **Lihat dan ubah:** Kamu dapat melihat dan memperbarui detail laporan langsung melalui halaman riwayat aplikasi.
- **Salin atau unduh:** Kamu dapat mengekspor atau membuat salinan data laporan ke file penyimpanan lokal.
- **Hapus:** Kamu dapat menghapus laporan kapan saja melalui tombol hapus (permanen, tidak bisa dikembalikan).

## 5. Perubahan Kebijakan
Jika kami menambah fitur yang mengirim data ke server pada milestone berikutnya, kamu akan diminta izin terlebih dahulu dan kebijakan ini akan diperbarui.
